Objective: exploit a library known to be vulnerable.
Methodology :

	1-Identify a feature relying on an external library.

	2-Determine the exact version of the library used.
	
	3-Scan for known vulnerabilities associated with this release.
	
	4-Exploit the identified vulnerability through the application interface.
	
	5-Observe the impact on the application’s behavior.
	
	6-Validate the challenge.
	
	Techniques used:
	Version analysis
	Exploitation of known vulnerability
	
	Tools:
	Web browser
	Development tools

Vulnerabilities:

	Type: Vulnerable and Outdated Components
	Affected component: Vulnerable third-party library
	Cause: Use of an outdated version containing known flaws	
	Estimated severity: High

Risks:

	Public exploitation of known vulnerabilities
	Unauthorized access or code execution
	Data compromise

Actions:

	Update libraries to secure versions
	Monitor the CVE of dependencies used
	Set up regular security audits
